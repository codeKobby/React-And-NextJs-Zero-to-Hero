# Day 002 practice: HTML, CSS, accessibility, and the DOM

Read the [lesson](../day_002_html_css_accessibility_and_the_dom.md) first. This is deliberately an observation worksheet, not a programming worksheet. Use a page you are allowed to inspect or the local starter from the [examples guide](../../examples/README.md). Record evidence in plain language and do not change production or public data.

## Exercises

1. Identify the main heading and explain what its level communicates.
2. Identify one link and one button; describe their different user intents.
3. Find a form control and its visible or programmatic label.
4. Navigate to three controls with the keyboard and record focus order.
5. Inspect one element and write its DOM tag, attributes, and likely role.
6. Turn off CSS and record which meaning remains visible from the structure.
7. Find one repeated card or row and describe its DOM relationship.
8. Observe a status or error message and explain how it could be announced.
9. Find one visual-only interaction and propose a native HTML repair.
10. Inspect contrast or reduced-motion behavior and record one uncertainty.
11. Apply the same observation method to the local Next.js starter.
12. Write a review note with evidence, one limitation, and one question for Day 003.
