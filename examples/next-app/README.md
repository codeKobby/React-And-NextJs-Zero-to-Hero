# Next.js App Router starter

This example intentionally uses `src/app` rather than a root-level `app` directory. The root contains configuration and `public`; application code lives under `src`.

```text
src/app/layout.tsx
src/app/page.tsx
src/components/interactive/Counter.tsx
src/lib/demo-data.ts
public/
package.json
next.config.ts
```

Run `pnpm install`, then `pnpm dev`. The example is deliberately small; the lessons add routes, boundaries, data access, forms, tests, and policies one step at a time.
