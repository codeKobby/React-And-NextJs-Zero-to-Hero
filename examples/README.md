# Example projects

The course uses two kinds of projects. React-only playgrounds isolate component and Hook behavior from framework routing. Next.js projects add App Router, server/client boundaries, data access, caching, streaming, and deployment concerns.

The manifests below record the modern baseline without committing a generated `node_modules` directory. Use the official CLI and the setup guide to create a runnable project when you reach the corresponding phase.

- [`react-playground-package.json`](react-playground-package.json): React 19.2.8 with Vite 8.2.2.
- [`next-app-package.json`](next-app-package.json): Next.js 16.3.1 with React 19.2.8.
