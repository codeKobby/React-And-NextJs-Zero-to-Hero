# Day 032 solution guide: useActionState and form actions

Use this guide only after attempting the numbered exercises in [the lesson](../day_032_useactionstate_and_form_actions.md). It reviews the decisions for **useActionState and form actions**; it is not a copied answer key.

## Review checkpoints

1. The learner can say what problem useactionstate and form actions solves in one or two simple sentences.
2. The example runs and the learner records the visible or returned result for a small local example.
3. The learner can point to the input, the important line, and the output.
4. The learner changes one input for What does useActionState return? and records the old and new result.
5. The learner tries a normal and an empty or bad value for How does a form action receive FormData?.
6. The learner reproduces `Read formData.get without checking its type and repair the validation boundary.` and writes down the error or wrong result.
7. The learner fixes the smallest line and runs the normal case again.
8. The learner uses local invented data to show Where should validation happen?.
9. The test or check fails when the visible behavior is removed and passes after it is restored.
10. The learner builds a small local example without exposing secrets or using real data.
11. The learner writes one thing the example does not prove about a real application.
12. The learner’s review note uses plain sentences and defines any technical word it needs.
